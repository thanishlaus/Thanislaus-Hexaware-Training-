# Working with CSV and JSON using PySpark

This project assessments demonstrates how to work with CSV and JSON files using PySpark DataFrames.

## Tasks Completed
### CSV Operations
- Loaded flights.csv file
- Displayed flight booking details
- Applied filters on booking status
- Performed aggregations and counts
- Calculated revenue and average ticket prices
- Created new columns using withColumn()
- Categorized ticket prices
- Saved data as Parquet file

### JSON Operations
- Loaded hotels.json file
- Accessed nested JSON fields
- Filtered hotel records
- Worked with array data using array_contains()
- Performed groupBy and aggregations
- Calculated total potential revenue
- Flattened nested JSON structure
- Saved flattened data as Parquet file
## Files Created
- flights.csv
- hotels.json
- confirmed_flights.parquet
- hotels_flattened.parquet

## Learning Outcomes
- Reading CSV files
- Reading JSON files
- Working with nested JSON data
- DataFrame transformations
- Filtering and aggregations
- Creating derived columns
- Exporting data in Parquet format
