# Apache Airflow Capstone Exercises

## Project Overview
This project demonstrates workflow automation using Apache Airflow and Python. Multiple DAGs were created to perform file processing, report generation, data analysis, and workflow orchestration tasks.
---

## Technologies Used
- Apache Airflow
- Python
- Docker
- Ubuntu (KillerCoda)

---

## Exercises Completed

### Exercise 7 – Department Salary Report
- Created department salary file
- Calculated total salary by department
- Generated department report

### Exercise 8 – Electricity Bill Summary
- Created electricity usage file
- Calculated total and average units
- Generated bill summary

### Exercise 9 – Exam Result Report
- Created result file
- Counted pass and fail students
- Generated result summary

### Exercise 10 – Online Orders
- Created orders CSV file
- Calculated product revenue
- Generated sales report

### Exercise 11 – Temperature Analysis
- Created temperature dataset
- Calculated highest and average temperature
- Generated weather report

### Exercise 12 – Bank Transaction Summary
- Created transaction file
- Calculated deposits, withdrawals, and balance
- Generated account report

### Exercise 13 – Employee Age Report
- Created employee age file
- Calculated youngest, oldest, and average age
- Generated age report

### Exercise 14 – Course Enrollment Report
- Created enrollment file
- Counted students in each course
- Generated course report
