# Azure Databricks Assessments
## Overview
This repository contains Azure Databricks assessments completed using PySpark. The assessments focus on Delta Lake concepts, data processing, ETL pipelines, hospital analytics, and data visualization.

## Topics Covered

- Reading CSV Files
- Reading JSON Files
- Schema Validation
- Data Cleaning
- Null Handling
- Join Operations
- Revenue Analysis
- Doctor Performance Analytics
- Hospital Service Analysis
- Window Functions
- Spark SQL
- ETL Processing
- Parquet File Handling
- Data Exploration
- Appointment Analysis
- Revenue Analysis
- Visualization Techniques
- Aggregation Functions
- Business Insights Generation
