# Week 4 – ETL using Azure Databricks

## Objective

Build an ETL pipeline to integrate product and warehouse inventory data.

## Tasks Completed

- Loaded inventory datasets into Azure Databricks.
- Performed joins between product and warehouse data.
- Created a master inventory view.
- Added reorder flags for inventory monitoring.
- Exported final inventory dataset.

## Technologies Used

- Azure Databricks
- PySpark

## Deliverables

- inventory_products.csv
- warehouse_status.csv
- master_inventory.csv
- Databricks Notebook

## Outcome

Successfully built an ETL pipeline and generated a consolidated inventory report for dashboarding and business analysis.
