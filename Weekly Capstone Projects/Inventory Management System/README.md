# Inventory Management System
## Project Overview

The Inventory Management System is an end-to-end data engineering and analytics project designed to manage inventory levels, monitor stock movements, and identify products that require restocking. The project integrates database management, data processing, big data analytics, ETL pipelines, and automation to provide efficient inventory tracking and decision-making.

## Objectives
* Manage product inventory across multiple warehouses.
* Track stock movement transactions.
* Identify low-stock and overstocked products.
* Generate inventory insights using Python and PySpark.
* Build ETL workflows using Azure Databricks.
* Automate inventory monitoring using Azure DevOps pipelines.

## Technologies Used

* MySQL
* MongoDB
* Python (Pandas, NumPy)
* PySpark
* Azure Databricks
* Azure DevOps
* Git & GitHub

## Project Workflow

### Week 1 – Database Foundations
* Design inventory database schema using MySQL.
* Implement CRUD operations.
* Create stored procedures for low-stock identification.
* Store audit logs using MongoDB.

### Week 2 – Stock Processing with Python
* Load and clean inventory data.
* Calculate current stock levels.
* Identify products below reorder threshold.
* Generate inventory reports.

### Week 3 – Warehouse Analytics with PySpark
* Process large-scale stock movement data.
* Analyze inventory distribution across warehouses.
* Detect overstocked and understocked items.

### Week 4 – ETL with Azure Databricks
* Build inventory data pipelines.
* Create master inventory views.
* Prepare data for reporting and dashboarding.

### Week 5 – Automation with Azure DevOps
* Automate daily inventory checks.
* Generate reorder reports.
* Schedule and monitor inventory workflows.

## Expected Outcomes
* Centralized inventory tracking system.
* Automated low-stock detection.
* Warehouse-level inventory analytics.
* Scalable ETL pipeline implementation.
* Automated inventory monitoring and reporting.
