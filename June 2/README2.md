# EdTech MongoDB Capstone Project

The database stores information about:
- Learners
- Instructors
- Courses
- Enrollments
- Payments
- Course Progress
- Quiz Scores

## Database Name
edtech_capstone_db

## Collections
1. learners
2. instructors
3. courses
4. enrollments

## Concepts Covered
- Find Queries
- Operators
- Array Queries
- Sorting and Limit
- Update Operations
- Delete Operations
- Count and Distinct
- Aggregation
- $lookup Joins
