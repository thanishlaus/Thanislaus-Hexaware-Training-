# MongoDB Food Delivery Capstone Project
The database stores information about:
- Restaurants
- Orders
- Delivery Partners
- Payments
- Ratings

## Database Name
```
food_delivery_capstone_db
```

## Collections Used
1. customers
2. restaurants
3. orders
4. delivery_partners

## Operations Performed

### Queries
- Display customer details
- Display restaurant details
- Filter records using conditions
- Search items inside orders
- Find orders based on item quantity and price

- Sort records
- Display top records
- Update customer, restaurant and order details
- Add and remove fields
- Delete records based on conditions
- Count documents
- Display unique values
- Revenue analysis
- Average delivery time
- Customer spending analysis
