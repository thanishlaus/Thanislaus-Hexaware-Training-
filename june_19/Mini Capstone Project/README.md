# Airline Operations Analytics Platform using Azure Databricks

## Project Overview
This mini capstone project focuses on building an Airline Operations Analytics Platform using Azure Databricks, PySpark, Delta Lake, and Spark SQL. The project implements a complete Data Engineering pipeline following Bronze, Silver, and Gold architecture.
---

## Project Objectives
- Ingest Airline Data
- Process and Transform Data
- Perform Exploratory Data Analysis
- Generate Business Reports
- Implement Delta Lake Features
- Create Automated Workflows

---

## Datasets Used
### Flights Dataset
Contains:
- Flight ID
- Airline
- Source City
- Destination City
- Duration
- Flight Status

### Bookings Dataset
Contains:
- Booking ID
- Flight ID
- Passenger Name
- Travel Class
- Ticket Price
- Booking Date

### Passenger Preferences Dataset
Contains:
- Passenger Name
- Meal Preference
- Seat Preference
