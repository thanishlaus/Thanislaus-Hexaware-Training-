# Retail Analytics Platform using Azure Databricks

## Project Overview

The Retail Analytics Platform is a Data Engineering and Analytics project developed using Azure Databricks, PySpark, Spark SQL, Delta Lake, and Databricks Workflows. The project processes retail sales data from multiple sources, performs data transformations, generates business insights, and demonstrates Delta Lake capabilities.

---

## Project Objectives

* Ingest retail datasets into Azure Databricks
* Process customer, product, order, and preference data
* Perform data transformations and data integration
* Generate retail business insights
* Create visual analytics dashboards
* Implement Spark SQL and Window Functions
* Demonstrate Delta Lake features

---
