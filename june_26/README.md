# DevOps, Agile, Scrum and SDLC Learning Notes

## Overview
This document summarizes the concepts learned about SDLC, IT Functional Areas, DevOps, Agile Methodology, Scrum Framework, Agile Meetings, Testing Types, and Software Delivery Process.
---

# Topics Covered
## 1. Software Development Life Cycle (SDLC)

### Phases of SDLC
- Requirement Gathering
- Wireframe Design
- Technical Design
- Development
- Testing (QA)
- Deployment
- Maintenance

### Key Documents
- Business Requirement Document (BRD)
- Software Requirement Specification (SRS)
- Technical Design Document (TDD)
- High Level Design (HLD)
- Low Level Design (LLD)

---

## 2. IT Functional Areas

### Architecture
Designs software architecture and technology solutions.

### Project Management
Plans, tracks, and manages project execution.

### Development
Builds and maintains software applications.

### Business Analysis
Collects and analyzes business requirements.

### Quality Assurance (QA)
Tests applications and ensures quality.

### Operations
Maintains production systems and infrastructure.

### Information Security & Compliance
Protects systems and ensures regulatory compliance.

### Centers of Excellence (CoE)
Provides expertise in specialized areas such as:
- ERP
- Content Management
- Integration

---

## 3. DevOps

### Definition
DevOps is a culture and practice that combines Development and Operations teams to improve collaboration, automation, and software delivery.

### DevOps Lifecycle
- Plan
- Develop
- Build
- Test
- Release
- Deploy
- Operate
- Monitor

### Popular DevOps Tools
- Git & GitHub
- Jenkins
- Docker
- Kubernetes
- Azure DevOps
- AWS

### Advantages of DevOps
- Faster deployments
- Improved collaboration
- Better software quality
- Reduced deployment failures
- Continuous monitoring
- Faster issue resolution

---

## 4. Agile Methodology

### Definition
Agile is an iterative software development methodology that focuses on delivering software in small increments and adapting to changing requirements.

### Agile Principles
- Customer collaboration
- Continuous delivery
- Flexibility to change
- Team collaboration
- Continuous improvement

### Benefits of Agile
- Faster delivery
- Better quality
- Improved customer satisfaction
- Reduced project risk
- Increased flexibility

---

## 5. Scrum Framework

### Definition
Scrum is the most commonly used Agile framework that organizes work into short development cycles called Sprints.

### Scrum Roles
- Product Owner
- Scrum Master
- Development Team

### Scrum Artifacts
- Product Backlog
- Sprint Backlog
- Increment

### Sprint
A Sprint is a fixed-duration iteration (usually 2–4 weeks) used to complete a set of tasks.

---

## 6. Important Agile Meetings

### Sprint Planning
Plans tasks for the upcoming sprint.

### Daily Scrum (Stand-Up)
A 15-minute daily meeting to discuss progress and blockers.

### Sprint Review
Demonstrates completed work to stakeholders.

### Sprint Retrospective
Discusses improvements for future sprints.

---

## 7. Software Testing Types

### Unit Testing
Tests individual modules or functions.

### Integration Testing
Tests interaction between multiple modules.

### System Testing
Tests the complete application.

### Black Box Testing
Tests functionality without knowing internal code.

### API Testing
Validates API requests and responses.

### Automation Testing
Uses tools to execute test cases automatically.

### Regression Testing
Ensures new changes do not affect existing functionality.

### Load Testing
Measures performance under expected user load.

### Stress Testing
Tests system behavior beyond normal capacity.

---

## 8. Software Environments

### Development Environment (DEV)
Used by developers for coding and initial testing.

### Testing Environment (TEST)
Used by QA team for functional testing.

### User Acceptance Testing (UAT)
Used by business users to validate requirements.

### Integration Environment (INT)
Used for testing integration between systems.

### Pre-Production Environment (PPE)
Final validation environment before deployment.

### Production Environment (PROD)
Live environment used by end users.
