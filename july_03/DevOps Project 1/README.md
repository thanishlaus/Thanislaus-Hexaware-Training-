# Azure DevOps CI/CD Pipeline for Customer Management System

## Project Overview
This project demonstrates the implementation of a simple **Customer Management System** using **Python** and the planning of a **Continuous Integration (CI) Pipeline** using **Azure DevOps**.
The project focuses on Agile Planning, Source Code Management, and CI pipeline configuration to automate the build and execution of a Python application.

---

## Objectives

- Create Agile work items using Azure DevOps Boards.
- Organize work into Epic, Features, User Stories, and Tasks.
- Develop a simple Python Customer Management application.
- Configure a Git repository for source code management.
- Create an Azure DevOps YAML pipeline.
- Automatically build and execute the Python application.
